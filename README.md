# 🚀 SR Infinity Super App

**One App. Multiple Services. Unlimited Possibilities.**

SR Infinity Super App is a modern Progressive Web App (PWA) designed to bring multiple web services together in one central dashboard.

## ✨ Features

- Modern responsive dashboard
- Multiple website modules
- QR Hub integration
- AI Assistant module placeholder
- Dark and Light mode
- Installable PWA
- Service Worker and offline dashboard caching
- Add new services from the dashboard
- Mobile and desktop support

## 📱 Installation

1. Open the website in a supported browser.
2. Wait for the page to load.
3. Select Install App or Add to Home Screen.
4. Launch SR Infinity Super App.

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- Progressive Web App
- Service Worker
- Web App Manifest

## 🔒 Security

- HTTPS is required for PWA features.
- API keys must never be exposed in frontend code.
- External websites may block iframe embedding.
